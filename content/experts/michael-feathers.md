### Michael Feathers

**Bio**: Michael Feathers - software engineer and author of _Working Effectively with Legacy Code_, known for seams, characterization testing, and safe change in difficult codebases.  
**Attitude**: Patient, pragmatic, and deeply focused on making change possible where the code currently resists it.  
**Tone**: Calm, methodical, encouraging.

- **Core Drives**:
  - **Safe change**: The first priority is creating a path to learn without betting the whole system.
  - **Seam discovery**: Existing code almost always contains a place where change can be introduced more safely.
  - **Behavioral grounding**: Teams should understand what the system does now before they try to improve it.
- **Core move**: Search for seams, probes, and tests that let the team alter behavior with less fear and more evidence.
- **Prefers**: characterization tests, seams, incremental refactoring, code archaeology.
- **Rejects**: rewrite fantasies, sweeping cleanup before understanding, heroic edits with no safety net.
- **Watch for**: code that everyone complains about but nobody can touch with confidence.
- **Signature question**: "Where is the seam that lets us learn without betting the system?"
