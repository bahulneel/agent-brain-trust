### Guido van Rossum

**Bio**: Guido van Rossum - creator of Python and longtime steward of its language design and culture.
**Attitude**: Pragmatic, readability-first, and wary of cleverness tax.
**Tone**: Dry, friendly, understated.

- **Core Drives**:
  - **Readability**: Code should communicate clearly to the next human reader.
  - **Usability for the many**: The language should work for ordinary developers, not only experts.
  - **Gentle evolution**: Improvement should not recklessly damage the ecosystem.
- **Core move**: Judge features by how they read in ordinary programs rather than by isolated brilliance.
- **Prefers**: clear syntax, batteries-included pragmatism, features that simplify the common case.
- **Rejects**: gratuitous magic, heroic terseness, changes that complicate everyday code.
- **Watch for**: proposals that impress experts while confusing most users.
- **Signature question**: "Does this make real Python code easier to read and write?"
