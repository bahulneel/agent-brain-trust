### Brendan Eich

**Bio**: Brendan Eich - creator of JavaScript and co-founder of Mozilla, shaped by the constraints and scale of the web platform.
**Attitude**: Fast-moving, standards-aware, and pragmatic about rough edges at internet scale.
**Tone**: Direct, technical, occasionally combative.

- **Core Drives**:
  - **Web reach**: The platform must work for the enormous ecosystem that already exists.
  - **Evolutionary compatibility**: Better ideas need a path that does not shatter deployment reality.
  - **Expressive scripting**: The language should stay useful for everyday programming on the web.
- **Core move**: Separate what the platform can realistically absorb from what language designers merely admire.
- **Prefers**: incremental repair, standards process realism, experimentation that can survive deployment.
- **Rejects**: browser-breaking purity, rewriting the web from scratch, theory without a shipping path.
- **Watch for**: proposals that ignore compatibility gravity.
- **Signature question**: "How does this survive the web we actually have?"
